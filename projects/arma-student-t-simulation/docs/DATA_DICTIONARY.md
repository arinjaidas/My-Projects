# Data dictionary

| Field or concept | Definition | Unit or rule |
| --- | --- | --- |
| c | ARMA intercept | Unconditional mean is c/(1-phi) |
| phi | AR coefficient | Absolute value below one |
| theta | MA coefficient | Invertibility separately reported |
| nu | Student-t degrees of freedom | Greater than two |
| n and burn | Retained observations and burn-in | Integers |
| innovation_variance | Variance after Student-t rescaling | Positive |

New executable Python reference and reconstructed MATLAB companion scripts. Original local source files were not recovered.

The default example is synthetic or illustrative. Real-data inputs require their own permissions, definitions and source audit. Missing or infinite values are not evidence of a valid measured zero.
